1. INTRODUCCIÓN
================================================================================

El objetivo de esta práctica es estudiar empíricamente la complejidad
temporal de tres implementaciones del cálculo del n-ésimo número de
Fibonacci.

Para cada algoritmo se miden los tiempos de ejecución sobre una progresión
geométrica de tamaños de entrada y se contrastan con tres cotas:
una subestimada, una ajustada y una sobreestimada.

Las unidades de tiempo empleadas en todas las tablas son microsegundos (µs).
Los tiempos se obtienen con la función proporcionada microsegundos().

Cuando el tiempo medido no supera el umbral de 500 µs se
ejecuta el algoritmo en un bucle de k iteraciones y se divide el tiempo
total entre k. Las filas afectadas se marcan con un asterisco (*) y se
indica el número de iteraciones empleado en el pie de cada tabla.

3.1  fib1
-----------

Complejidad teórica: Θ(φⁿ)  con φ = (1+√5)/2

Cotas:
  · Subestimada   : 1.1ⁿ
  · Exacta        : φⁿ
  · Sobreestimada : 2ⁿ

=================================== TABLA DE TIEMPOS FIB1 ===================================

           n            t(n)            t(n)/1.1^n           t(n)/phi^n             t(n)/2^n
----------------------------------------------------------------------------------------------
           2        0.003483*             0.002879             0.001330           0.00087075
           4        0.009022*             0.006162             0.001316           0.00056388
           8        0.056073*             0.026158             0.001194           0.00021904
          16        2.564003*             0.558002             0.001162           0.00003912
          32     5721.000000            270.960524             0.001175           0.00000133
----------------------------------------------------------------------------------------------
*: tiempo promedio de 1000000 ejecuciones

Análisis:
  · t(n)/1.1ⁿ  tiende a infinito       →  1.1ⁿ es una cota subestimada.
  · t(n)/φⁿ    oscila sobre el 0.0012  →  φⁿ es la cota ajustada.
  · t(n)/2ⁿ    tiende a 0              →  2ⁿ es una cota sobreestimada.

Las cuatro primeras filas se miden en un bucle (k = 1 000 000) ya que los
tiempos individuales son inferiores a 500 µs. Para n = 32 el tiempo
supera ese umbral y se mide directamente.

No se detectan mediciones anómalas.

3.3  fib3
----------

Complejidad teórica: Θ(log n)

Cotas:
  · Subestimada   : √(log n)
  · Exacta        : log n
  · Sobreestimada : √n

=================================== TABLA DE TIEMPOS FIB3 ===================================

           n            t(n)     t(n)/sqrt(log(n))          t(n)/log(n)         t(n)/sqrt(n)
----------------------------------------------------------------------------------------------
        1000        0.018190*             0.006921             0.002633           0.00057522
       10000        0.026720*             0.008804             0.002901           0.00026720
      100000        0.031610*             0.009316             0.002746           0.00009996
     1000000        0.037610*             0.010119             0.002722           0.00003761
    10000000        0.040830*             0.010170             0.002533           0.00001291
----------------------------------------------------------------------------------------------
*: tiempo promedio de 100000 ejecuciones

Análisis:
  · t(n)/√(log n)  crece lentamente        →  √(log n) es cota subestimada.
  · t(n)/log n     oscila sobre el 0.0027  →  log n es la cota exacta.
  · t(n)/√n        tiende a 0              →  √n es cota sobreestimada.

Todos los tiempos son inferiores a 500 µs, por lo que todas las filas se miden 
en un bucle (k = 100 000). El cociente t(n)/log n oscila entre 0.002901 y 0.002533, 
una variación que puede ser provocada por la medición de tiempos tan pequeños.

No se detectan mediciones anómalas.


================================================================================
4. CONCLUSIÓN
================================================================================

Los tres algoritmos han sido testeados: producen
resultados iguales para n = 1...30.

El análisis empírico confirma las complejidades teóricas esperadas:

  ┌───────────┬──────────────┬──────────────────┬─────────────────┐
  │ Algoritmo │ Complejidad  │ Cota ajustada    │ Constante aprox.│
  ├───────────┼──────────────┼──────────────────┼─────────────────┤
  │ fib1      │ O(φⁿ)        │ φⁿ               │ c ≈ 0.0012      │
  │ fib2      │ O(n)         │ n                │ c ≈ 0.0018      │
  │ fib3      │ O(log n)     │ log(n)           │ c ≈ 0.0027      │
  └───────────┴──────────────┴──────────────────┴─────────────────┘

fib3 es claramente el más eficiente para valores grandes de n: para
n = 10 000 000 tarda ≈ 0.040830 µs frente a los 17 958 µs de fib2, mientras
que el tiempo de fib1 es insostenible. La diferencia entre fib2 y fib3 crece
cada vez más al aumentar n.

Esta es una clara demostración de la diferencia de velocidad de un algoritmo 
de complejidad logarítmica frente a una complejidad lineal para una entrada
suficientemente grande.
